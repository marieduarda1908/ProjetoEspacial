## Descrição do Projeto

Este projeto foi desenvolvido para a Global Solution da disciplina de Programação Orientada a Objetos (POO).

O sistema simula uma Plataforma de Monitoramento Espacial capaz de monitorar sensores, controlar sistemas de propulsão e gerenciar dados de uma missão espacial.

## Conceitos de POO Aplicados

### Classe Abstrata

* ComponenteEspacial
* SistemaPropulsao

### Interface

* Sensor

### Encapsulamento

* DadosMissao
* Proteção de coordenadas por senha
* Validação de combustível

### Herança

* PropulsaoQuimica
* PropulsaoEletrica

## Funcionalidades

* Monitoramento de sensores de temperatura, pressão e radiação
* Sistema de alertas
* Controle de propulsão química e elétrica
* Gerenciamento dos dados da missão
* Proteção de coordenadas através de senha
* Exibição de status completo
* Menu interativo
